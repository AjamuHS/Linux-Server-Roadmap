# linux-server-roadmap
First Project - Creating a Linux Bash script that can analyze and showcase Server Performance stats.

## First Step
1. **Clone the repository as shown below**
   ```  
   git clone https://github.com/AjamuHS/linux-server-roadmap.git
   cd server-performance-statistics
   ```

## Second Step
2. **Make script into an executable**
   In order to run the server-stats.sh script, it needs to be granted permission to be executable as shown:
  ```
   chmod +x server.stats.sh
  ```

## Third and Final Step
3. **Execute the script and verify**
   After the script has been granted execution permission, simply run it using the below command:
   ```
   ./server-stats.sh
   ```
